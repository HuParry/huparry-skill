# 常规题（含特殊判题）

## 判题选择

唯一离散答案按题意选择普通文本/token 比较；先核实平台默认比较规则，不盲加 checker。精度、顺序可交换、构造、多解或证书输出需要相应语义 checker。SPJ 不把题型改成 interactive。

普通题的 `.out/.ans` 保存真实标准输出。SPJ 的答案文件可以保存存在性结论或其他裁判依据，但要明确解释为什么无需保存标程输出的全部构造。

## 标准答案

用可信解法生成全套标准答案。小规模用独立暴力/性质校验；避免生成器和标程同源逻辑出错后互相“证实”。构造题除确认能构造外，还检查 NO 分支的不可行性判断。

## SPJ 必查

- testlib 通常用 `registerTestlibCmd(argc, argv)`，`inf` 为原始输入，`ouf` 为选手输出，`ans` 为参考答案。依赖要可用。
- 首个 YES/NO 等判定 token 本身必须合法，不能读完后忽略。
- 验证全部数学条件，而不是只验证标准答案展示过的性质；不要求选手构造与标程相同。
- 检查范围、整数性、去重、计数、允许的额外空白与尾随内容；约定与题面一致。
- 整数几何优先使用平方距离、叉积、点积。根据最坏乘积决定 `long long` / `__int128`，不要先在较窄类型溢出再转换。
- 浮点只在题目确有浮点误差语义时使用，明确绝对/相对容差、NaN/Inf 处理。

样例三角形提示：三个点若要求两直角边长为 a,b，应确认某顶点两条边的平方长度为 a²,b²且点积为 0；还需非退化、坐标界限及三条边均不平行坐标轴。只排序三边后比较最短两边长度不足以保证直角。

## 验证

至少比较一份合法的非标程构造，以及一个只满足部分条件的伪构造。普通题对典型错误解检出，SPJ 额外测试非法判定词、边界坐标、退化、格式错误和错误 NO/YES。
